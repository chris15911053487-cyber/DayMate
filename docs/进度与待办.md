## 二、各里程碑结果

### M0 骨架
- npm workspaces 单仓库：`apps/web`（React 19 + Vite + Tailwind 4）、`apps/server`（Fastify 5 + Drizzle + PostgreSQL 17）、`packages/shared`。
- Docker Compose：app、db、caddy（HTTPS，只开 3101，不占 80）、backup（每天 3 点 pg_dump，留 14 天）、mailpit（开发）。`https://localhost` 可访问。
- 主题：用户确认 12 套都保留（经典 4 套：暖纸手账、极简黑白、夜航、水墨；个性 8 套：像素游戏、赛博霓虹、复古终端、千禧糖果、孟菲斯、蒸汽波、号外报纸、工程蓝图）。每套主题有 WCAG 对比度自动检查（108 项）。
- 与方案的差异：Node 用 22 LTS（与本机一致），不是 24。

### M1 账号
- 用户名或邮箱 + 密码；Argon2id；连续输错 5 次锁 15 分钟；IP 限流。
- 访问令牌只放内存，刷新令牌放 HttpOnly Cookie、每次刷新都换新，旧令牌被再次使用就作废会话；多标签页并发刷新已处理。
- 邮箱验证、找回密码（Mailpit 收信）、登录设备列表（可踢设备）、改密码、注销（7 天冷静期）。
- 测试中修掉：部署版里页面地址（如 `/me`）会撞到同名接口 → 非 `/api` 地址一律只当页面处理。
- 规则调整：未验证的邮箱也能找回密码，重置成功后视为已验证。

### M2 日历与记录
- 日历本（5 种语义色）、日程（全天 / 带时间 / 跨天）、重复（每天 / 工作日 / 每周 / 每月 / 每年，可设截止）、待办、当天记录（自动识别 #标签）、月 / 周 / 日视图、今天页、搜索、时区设置。删除 30 天内可撤销。
- 时区和重复规则自写（前后端共用，测过夏令时、闰年 2 月 29 日、每月 31 日）。
- 验收：每周一 9 点例会在月视图正确显示；时区改成东京显示 10:00，改成洛杉矶落到周日。

### M3 语音 + AI
- 录音和"按住说话"移植自 online-report；识别用百度短语音（标准版），解析用 DeepSeek（`deepseek-v4-flash`），**目前沿用 online-report 的密钥**。
- 一句话拆成多张可编辑卡片（日程 / 待办 / 记录，可换类型、可删），保存时全部成功或全部不保存；冲突提示；提问会先查数据再回答；AI 出错时原话存成记录草稿；轻点按钮 = 打字；"按住接着说"把新说的话接在后面。
- 评测集 40 条（`apps/server/eval/`）：首轮 38/40，补一条规则（重复事项一律是日程）后连续两轮 40/40，平均约 1.5 秒 / 句。
- 真实语音全链路（macOS 合成中文语音 → Chrome 假麦克风 → 百度 → DeepSeek → 保存）在开发版和 Docker 版都跑通；一次百度把"交"听成"叫"，AI 自己标注并按"交"处理。

### M4 提醒与推送
- 提醒队列 + 后台调度（30 秒一轮、行锁防重复发；停机错过 30 分钟以上只写站内"错过的提醒"）；重复日程发完自动排下一场；有截止时间的待办到点提醒。
- 统一出口 `notify()`：站内消息 → Web Push → 邮件，每个渠道的结果都记录；免打扰只拦早报和建议。
- 消息中心 + 铃铛未读数 + 应用开着时页内弹出提醒。
- PWA：manifest、主屏幕图标、Service Worker（只管推送）；设置页按设备开关推送，并说明收不到的原因（微信、非 HTTPS、iPhone 未添加到主屏幕、国内 Chrome）。
- AI 早报 / 晚间复盘：到点生成并推送，今天页显示；模型不可用时规则兜底；7 天未使用的用户不生成；提示词带当前时间，不会建议已过去的时段。
- 测试中修掉：web-push 4.x 导入方式变化导致启动失败、原生 SQL 里的时间参数格式、只改一个推送开关时保存失败、测试通知后铃铛不刷新。
